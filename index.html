Laporan harian & bulanan

Laporan dirangkum dari catatan produksi yang sudah disimpan. Pilih periode untuk melihat total produksi, nilai kotor, biaya, bagian bos, bagian anggota, dan bonus spiral.

Catatan pembacaan laporan

Laporan hanya menghitung produksi yang telah disimpan. Kas bos dan kas anggota tetap ditampilkan di menu masing-masing dan tidak otomatis digabung dengan nilai produksi, untuk menghindari penghitungan ganda.

Backup & pemulihan data

Backup: simpan salinan seluruh data aplikasi sebagai file JSON di HP. Lakukan rutin dan simpan file di tempat aman.

Pemulihan: pilih file backup GRUP 57 MATTUJU yang pernah disimpan. Data yang sekarang akan diganti dengan isi backup setelah kamu mengonfirmasi.

Data masih tersimpan di browser HP ini. Jangan hapus data browser sebelum membuat backup.

Catatan keamanan

File backup berisi data produksi, anggota, dan keuangan. Jangan bagikan kepada orang yang tidak berwenang. Pemulihan hanya berlaku pada browser/perangkat tempat file dipilih.
